# 统一器件可靠性接口 v2

旧式单一 `raw_bit_read_error_probability` 无法区分 SRAM 的驻留状态错误和 ROM 的本次读取瞬态。本工程采用 `interfaces/device_reliability_v2.schema.json`，明确分为：

1. `persistent_state`：可写状态随时间发生的翻转率；固定掩膜 ROM 不适用。
2. `transient_read`：状态原本正确时，本次读取因数据通路 SET 失败的概率。
3. `post_write`：写操作结束后状态错误的条件概率。
4. `correlated_macro_event`：地址、控制或 SEFI 等不能按独立 bit 处理的事件。
5. `permanent_failure`：TID、位移损伤或破坏性 SEE 导致的永久失效。

每个通道都带 `status`、`valid_for_target`、`search_ready`、归一化口径和限制。`missing` 不是零；下游不得把缺失通道自动填 0 后声称总 BER。

当前 SRAM 的 `persistent_state` 为工程数量级可用；当前 ROM 仅有 `transient_read.heavy_ion_lower_bound`。两个器件都缺宏级相关事件和目标版图/PDK 标定。
