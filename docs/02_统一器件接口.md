# 统一器件可靠性接口 v2

旧式单一 `raw_bit_read_error_probability` 无法区分 SRAM 的驻留状态错误和 ROM/MRAM 的本次读取瞬态。本工程采用 `interfaces/device_reliability_v2.schema.json`，明确分为：

1. `persistent_state`：可写状态随时间发生的翻转率；固定掩膜 ROM 不适用；SOT-MRAM 因无目标宏 σ 且文献报告 MTJ 本征抗 HI 翻转，当前为 `missing`。
2. `transient_read`：状态原本正确时，本次读取因数据通路 SET 失败的概率。
3. `post_write`：写操作结束后状态错误的条件概率；掩膜 ROM 不适用。
4. `correlated_macro_event`：地址、控制或 SEFI 等不能按独立 bit 处理的事件。
5. `permanent_failure`：TID、位移损伤或破坏性 SEE 导致的永久失效。

每个通道都带 `status`、`valid_for_target`、`search_ready`、归一化口径和限制。`missing` 不是零；下游不得把缺失通道自动填 0 后声称总 BER。

## 三器件通道对照（2026-08-28）

| 通道 | SRAM | ROM | SOT-MRAM |
|---|---|---|---|
| `persistent_state` | **available**，`search_ready=true`（实测代理驻留） | `not_applicable`（固定掩膜） | `missing`（无目标宏 σ） |
| `transient_read` | `missing`（读外围未建模） | **screening_only**，HI 下界 | **screening_only**，HI + 质子下界（方法同 ROM） |
| `post_write` | screening_only（写/hold Qcrit 比） | `not_applicable` | screening_only（SOT 写窗口 Qcrit） |
| `correlated_macro_event` | missing | missing | missing |
| `permanent_failure` | missing | missing | missing |
| `claim_level` | engineering_order_of_magnitude | incomplete_lower_bound | incomplete_lower_bound |
| 主交付文件 | `sram_device_delivery.json` | `rom_device_delivery.json` | `mram_device_delivery.json` |

**对齐关系：**

- SOT-MRAM 的读链（Qcrit → RPP → SPENVIS LET）与 ROM **对齐**。
- SOT-MRAM 故意**不对齐** SRAM 的 `persistent_state` 交付；二者物理量不同，禁止横向比大小。
- MRAM 相对 ROM 多交付：质子读窗口下界、写路径 Qcrit 筛选；二者仍同为 `incomplete_lower_bound`，且 `search_ready=false`。

当前三器件都缺宏级相关事件和目标版图/PDK 标定。
