# 下一步工作

按对结论有效性的影响排序：

1. 获取目标或结构相近 SRAM 宏的完整 `σHI(LET)`、`σp(E)`、MBU 多重度和测试模式；替换当前跨器件代理并重新积分。
2. 为 SRAM 补充“状态正确时的动态读取外围”截面：位线、感放、列选、地址译码和控制路径分别评估，宏级 SEFI 单列。
3. 为 ROM 获取可归一化到 per-access 的动态质子数据，必须同时公开访问频率、输出宽度、错误定义和捕获窗口；没有这些信息时不得给 ROM 绝对总 BER。
4. **SOT-MRAM（在现有 ROM 对齐读链之上）：**
   - 增加流片锚点工作点（如 LED 2024 / arXiv:2404.09125：R_P≈10.89 kΩ、TMR=119%、Ic≈680 μA@2 ns），与 §7.1 compact 基线双轨对照；
   - 有束流数据后再把 `transient_read` 从 screening 推向可标定截面；
   - 勿在无目标宏 σ 时强行填充 `persistent_state`。
5. 用目标 PDK Monte Carlo 和 PEX 替换 PTM32、工程失配先验、线性位线电容和面积代理；重跑访问、Qcrit 与阵列 LUT（SRAM / ROM / MRAM 读列共用）。
6. 有版图后再决定是否接入 Geant4/G4SEE/TCAD。它们用于粒子输运与电荷沉积/收集，不替代电路 Qcrit，也不能在无独立校准时自动产生可信绝对截面。
7. 在接口中加入 MBU/ECC、相关宏事件和永久失效后，才生成跨器件“总工作负载错误率”。

不要优先增加更多没有目标数据约束的 Monte Carlo 档位；当前最大的误差来自目标响应曲线、动态外围和版图电荷收集，而不是积分精度。
