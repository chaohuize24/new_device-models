# 组会一页结论

更新日期：2026-08-29  
任务环境：400 km、51.6°、约 5 年、1.0 g/cm² Al 等效屏蔽

## 一句话

本工程按**五个独立通道**交付 SRAM / ROM / SOT-MRAM 的辐射错误量级；**禁止**把三者合成或排序成一个“总 BER”。

## 三器件各交什么数


| 器件           | 主通道                | 中心工程数          | 含义                             | claim                  |
| ------------ | ------------------ | -------------- | ------------------------------ | ---------------------- |
| **SRAM**     | `persistent_state` | **1.29×10⁻¹⁰** | 1500 s 已知正确重写后，随机读到**已翻状态**的概率 | 数量级包络（28 nm 代理 σ）      |
| **ROM**      | `transient_read`   | **1.26×10⁻²⁵** | 单次读、0.72 ns 窗内重离子 SET **下界**   | incomplete_lower_bound |
| **SOT-MRAM** | `transient_read`   | **1.42×10⁻²⁴** | 同上方法论（§7.1 默认）；另有质子读下界         | incomplete_lower_bound |


机器可读：`interfaces/{sram,rom,mram}_device_delivery.json`。

## 为何不能横比


| 对比               | 为什么不行                                        |
| ---------------- | -------------------------------------------- |
| SRAM vs ROM/MRAM | SRAM 是**存着就可能翻**；ROM/MRAM 当前交的是**这次读被打坏**的下界 |
| ROM vs MRAM 读窗   | 同方法论，但敏感体/网表不同；可比量级趋势，不可比“谁更好”到小数点           |
| 把通道相加            | 缺并集模型；缺失通道 ≠ 0                               |




## MRAM 双轨：读几乎一样，写差几个数量级


| 量                  | §7.1 compact（默认） | fab_led_2024（流片 R/TMR）        |
| ------------------ | ---------------- | ----------------------------- |
| 读窗 HI nominal      | **1.417×10⁻²⁴**  | **1.296×10⁻²⁴**（约 **0.915×**） |
| 读窗质子下界 nominal     | 3.044×10⁻¹⁹      | 3.026×10⁻¹⁹（约 **0.994×**）     |
| 写 Qcrit / hold（快筛） | ≈ **1.0**        | **>81920**（右删失 ≥512 fC）       |
| 写电流 / 脉宽           | 100 μA / 1 ns    | 1020 μA / 2 ns                |


**解读：** 换成流片 R/TMR（~10.9 kΩ、TMR 119%）后，**读窗几乎不动** → 默认交付继续用 §7.1。真正分歧在**写电流量级**（80–100 μA 电路 compact vs 680 μA 级流片），写结果只作 screening，不作写 BER。

详见 [mram/results/dual_track_fab_vs_7_1.md](../mram/results/dual_track_fab_vs_7_1.md)。

## 诚实边界（汇报时必说）

1. 电路（ngspice + PTM32）只给功能 / 裕量 / Qcrit；**绝对截面**靠代理或束流标定。
2. MRAM `persistent_state` = **missing**（无目标宏 σ，不套用 SRAM 代理）。
3. 三器件均未完整计入译码/SEFI、永久失效；ROM/MRAM 读窗不含完整动态质子并集。
4. 当前最大误差源：目标响应曲线、动态外围、版图电荷收集——**不是**再多跑 Monte Carlo。
