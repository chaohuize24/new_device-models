# 工程状态与可信边界

更新日期：2026-08-24

## 1. 当前链条

```text
目标轨道与屏蔽
  → SPENVIS 屏蔽后 LET/质子能谱
  → 器件响应曲线 σ(LET) / σ(E)
  → 数值积分得到物理事件率
  → 状态驻留或访问窗口模型
  → 单 bit/单次访问交付量
```

电路仿真只负责响应侧：访问是否功能正确、裕量、延时、能量和 Qcrit。它不能单独产生可信粒子截面；绝对截面仍需要同类器件束流数据，或版图/输运/电荷收集模型的独立标定。

## 2. SRAM：可以使用的结果

目标任务为 400 km 圆轨道、51.6° 倾角、2020-01-01 至 2024-12-30、1.0 g/cm² Al 等效屏蔽。采用公开 28 nm memory-class 实测响应代理：

| 场景 | SBU率 (/bit/s) | 1500 s内随机读取BER | 1500 s末端BER |
|---|---:|---:|---:|
| partial_low | 5.738177e-14 | 4.303633e-11 | 8.607265e-11 |
| engineering_nominal | 1.717746e-13 | 1.288309e-10 | 2.576619e-10 |
| engineering_high | 9.039518e-13 | 6.779639e-10 | 1.355928e-09 |

这些场景不是统计置信区间：低档仅计入有实测支撑的部分能段；中档跨两种 28 nm memory technology 连接 8–80 MeV 缺口；高档对该缺口采用保守平台。它们适合数量级和敏感性研究，不适合宣称某一目标 SRAM 宏的精确 BER。

读 BER 的定义是“读取时存储状态已经错误”。当前未计入状态仍正确时，感放、位线、列选或地址控制受到 SET 造成的本次访问错误。

写窗口列只是使用 1.55 ns 窗口和静态 SBU 率形成的筛选量。随附双指数注入表明当前选中写路径的最坏非压力角 `Qcrit_write/Qcrit_hold=0.9301`，但没有动态束流截面，所以不能把该筛选量称为目标写 BER。

## 3. SRAM：验证到了什么

- 谱解析、单位换算和同一响应曲线的积分实现与 SPENVIS 数值在 0.1% 内一致。
- HM628128/RXTE 的两个月均在轨率锚点未用于拟合响应曲线；本地预测/公开在轨日均率分别为 1.631 和 2.088。它支持事件率链条的数量级能力，不构成目标 28 nm SRAM 的验证。
- PTM32 访问扫描在声明的 PVT/TID 与失配代理中未观察到功能失败；有限样本的“零失败”只表示条件筛选通过，不等于真实 BER 为零。

## 4. ROM：可以使用的结果

ROM 网表为 2048×128 MASK NOR-ROM 的代表性差分列路径：256 行局部段、CMOS 分段选择、4:1 列选、全局差分位线、dummy reference 和时钟差分锁存感放。代码图案通过选中段内存在的未选单元 NMOS 数量进入漏电与负载，不是“每个位置固定相同晶体管状态”。

随附链条联合扫描器件散布、TID 工程角、寄生、感放失调、动态噪声、注入节点与时刻，得到 384 条 Qcrit 记录，再用 RPP 敏感体工程包络生成重离子截面并积分目标 LET 谱。

| 场景 | 连续敏感重离子率 (/bit/s) | 0.72 ns active-bit读窗口概率 |
|---|---:|---:|
| low | 3.059807e-19 | 2.203061e-28 |
| nominal | 1.747842e-16 | 1.258446e-25 |
| high | 4.661461e-14 | 3.356252e-23 |

绝对值主要受假设的敏感面积、深度和收集效率支配，因此只能叫“重离子读窗口工程下界”。它不含动态质子响应、外围译码/控制 SET、SEFI 或永久故障，当前 `search_ready=false`。

## 5. TID、位移损伤和外围

- 14.32 krad(Si) 的 28 nm TID 只采用文献锚定的中心/保守/压力工程角，不是 foundry compact-model 拟合。
- 环境目录保留了规范化 TID/LET 输入所需工作簿；本工程没有把 NIEL 转成晶体管参数退化，因此不输出位移损伤后的 BER。
- SRAM 地址译码器、控制树和宏级 SEFI 未进入瞬态网表；ROM 也只建模代表性读列路径。
