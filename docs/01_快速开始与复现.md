# 快速开始与复现

## 环境

- macOS 或 Linux；
- Python 3.11+；
- `numpy`、`openpyxl`、`pytest`；
- 需要重跑电路时安装 `ngspice`。

推荐在工程根目录运行。快速检查：

```bash
python3 -B -m pytest -q -p no:cacheprovider
```

## SRAM 核心结果

重算目标谱与公开代理截面的积分：

```bash
python3 sram/scripts/run_sram_joint_proxy_chain.py
python3 sram/scripts/build_sram_target_orbit_final_ber.py
```

最终人工可读表：

- `sram/results/final_ber/final_read_write_ber.csv`
- `sram/results/final_ber/refresh_interval_sweep.csv`
- `sram/results/final_ber/README.md`

验证 RXTE 数量级锚点：

```bash
python3 sram/validation/xte/run_xte_validation.py
```

只做安装/一致性检查而不覆盖发布表时，可加
`--output-dir /tmp/xte_validation_check`。

## SRAM 电路与阵列代理

以下命令需要 `ngspice`：

```bash
python3 sram/scripts/run_ptm32_access_engineering_mc.py --jobs 8
python3 sram/scripts/run_ptm32_write_strike_screen.py --jobs 8
python3 sram/scripts/run_ptm32_architecture_lut.py --jobs 8
```

完整运行会覆盖相应 `sram/results/` 子目录。日常查看无需重跑；修改单元尺寸、PVT/TID、位线深度、列复用、时序或模型卡后才需要重跑。

## ROM

快速电路扫描需要 `ngspice`：

```bash
python3 rom/scripts/sweep_rom_spice_response.py
python3 rom/scripts/sweep_rom_periodic_500mhz.py --vdd 1.0 --temperature-c 27 --n-present 128 --parasitic-scale 1 --dvth-sa-mv 0 --tid-corner central
```

完整 Qcrit 统计扫描与重离子积分：

```bash
python3 rom/scripts/rom_heavy_ion_pipeline.py characterize --samples 64 --tolerance-fc 0.5
python3 rom/scripts/rom_heavy_ion_pipeline.py cross-section
python3 rom/scripts/summarize_read_ber.py
```

安装验证可用 `--samples 2` 做 smoke test，并把 `--output` 指向临时文件；不要用两样本结果替换发布表。

## SOT-MRAM

与 **ROM 同方法论**（读列 Qcrit + RPP + LET）；电气基线为参数汇总 §7.1（10 kΩ / 20 kΩ）。默认 ngspice 路径在 `mram/configs/pipeline_defaults.json`（可设 `NGSPICE` 或传 `--ngspice`）。

查看已发布结果无需重跑：`mram/results/README.md`、`interfaces/mram_device_delivery.json`。

完整重离子交付链（约 20–40 min）：

```bash
python mram/scripts/run_sot_mram_delivery.py
```

或分步：

```bash
python mram/scripts/sot_mram_heavy_ion_pipeline.py characterize --samples 64 --tolerance-fc 0.5
python mram/scripts/sot_mram_heavy_ion_pipeline.py cross-section
python mram/scripts/summarize_read_ber.py
```

质子读窗口（依赖同一 Qcrit TSV）：

```bash
python mram/scripts/run_mram_proton_read_integration.py
```

读路径功能变体 / 写窗口筛选（双轨）：

```bash
python mram/scripts/run_read_path_sensitivity.py
python mram/scripts/run_sot_write_strike_screen.py --quick
python mram/scripts/run_sot_write_strike_screen.py --quick \
  --config configs/sot_write_strike_screen_fab_led_2024.json \
  --output-dir results/write_strike_screen_fab_led_2024
```

对照说明：`mram/results/dual_track_fab_vs_7_1.md`。

安装验证可用 `characterize --samples 2` smoke test；不要用两样本结果替换发布表。改参后若已有 Qcrit，可：

```bash
python mram/scripts/run_sot_mram_delivery.py --skip-characterize
```

## 修改参数后需要重跑什么

- 只改 SRAM 驻留/重写间隔：仅重跑 `build_sram_target_orbit_final_ber.py`，或直接查 `refresh_interval_sweep.csv`。
- 改 SRAM 轨道谱或响应代理：先跑 `run_sram_joint_proxy_chain.py`，再跑最终 BER。
- 改 SRAM 单元、位线、列复用、PVT/TID 或时序：重跑相应 ngspice 脚本；如影响最终操作窗口，再重跑最终 BER。
- 改 ROM 总行数、分段行数、列复用、读时序、网表或模型：从 `characterize` 开始全部重跑。
- 只改 ROM 逻辑读取宽度且电气组织不变：只重跑 `summarize_read_ber.py`。
- 改 SOT-MRAM MTJ 读代理、读时序或阵列组织：从 `mram/.../characterize` 全部重跑，再跑质子积分并更新 `interfaces/mram_device_delivery.json`。
- 只改 SOT-MRAM 逻辑读取宽度：只重跑 `mram/scripts/summarize_read_ber.py`。
- 只改 SOT-MRAM 写电流/写脉冲：重跑 `run_sot_write_strike_screen.py`（不必重跑读 Qcrit）。
