# 文件清单与来源

## 顶层

- `README.md`：工程入口和当前核心数值。
- `requirements.txt`、`pyproject.toml`：Python 依赖和测试配置。
- `tests/test_release.py`：公式、结果、接口和目录卫生检查。
- `docs/06_组会一页结论.md`：三器件交付数字、不可横比理由与 MRAM 双轨摘要（组会/交差）。

## environment

- `target_orbit/average_LET_proton_and_ion_spectra.txt`：目标 SPENVIS 原始机器输入，同时包含 LET 与屏蔽后质子能谱块。
- `target_orbit/SPENVIS_环境与模型输入.xlsx`：重新构建的干净工作簿，只含任务摘要、LET/质子谱和 3.7 mm NIEL 汇总。
- `target_orbit/metadata.json`：轨道、屏蔽、模型和归一化口径。
- `target_orbit/raw/niel_parameters.txt`、`raw/tid_depth_dose.txt`：位移损伤与深度剂量的原始 SPENVIS 数值来源；不直接转换成晶体管退化。

## models

- `PTM_bulk/32nm_LP.pm`：University of Minnesota PTM 预测模型。只保留实际使用的 LP 卡，不携带未使用的 HP/22 nm 卡。
- `MTJ/sot_mtj_parameters.json`、`MTJ/SOURCE.md`：SOT-MRAM 电气/磁性参数与文献来源（默认 §7.1；流片锚点为补充）。

## sram

- `inputs/`：当前响应包络实际使用的公开实测代理点/Weibull 参数。
- `src/sram_check/`：谱解析、截面积分和状态演化最小代码闭包。
- `configs/`：当前五条正式流程的唯一配置。
- `netlists/`：访问、架构 LUT 和写入注入的当前 PTM32 网表。
- `scripts/`：与上述正式流程一一对应的脚本。
- `results/radiation/`：谱—响应积分的分量和总 rate。
- `results/final_ber/`：1500 s 固定重写假设与驻留时间扫描。
- `results/access_screen/`：条件访问功能和裕量。
- `results/architecture_lut/`：相对延时/动态能量/面积表；xlsx 是人工交付主表。
- `results/write_strike_screen/`：动态写路径 Qcrit/hold Qcrit 筛选。
- `validation/xte/`：独立地面 HM628128 响应、两个任务谱和月均在轨率数量级检查。

## rom

- `netlists/`：当前唯一主层级读列网表。
- `configs/`：统计/Qcrit/RPP 与 14.32 krad(Si) TID 工程角。
- `scripts/`：功能扫描、完整 Qcrit—重离子流程和读取宽度聚合。
- `results/`：由随附代码重新生成的当前结果。
- `docs/`：TID 参数包络和文献依据。

## mram

- `netlists/`：层次化 1T1MTJ 读列（与 ROM 同结构外围）及 `sot_dynamic_strike/` 写窗口筛选网表。
- `configs/`：统计包络、读路径变体、写筛选、质子 LET 代理、pipeline 默认 ngspice 路径。
- `scripts/`：功能扫描、Qcrit—重离子交付链、质子积分、写 strike 筛选、读路径敏感性。
- `results/`：Qcrit TSV、HI/质子截面与率、读 BER 宽度聚合、写筛选结果。
- `docs/00_可信边界.md`：MRAM 专用建模范围与不可声称内容。

## interfaces

- `device_reliability_v2.schema.json`：分通道接口定义。
- `sram_device_delivery.json`、`rom_device_delivery.json`、`mram_device_delivery.json`：下游机器入口。

所有文件均属于当前复现闭包；工具安装目录、第三方源码镜像、大型参考 PDF、缓存和阶段性报告不在发布包内，文献通过 `docs/03_参考资料.md` 的稳定链接引用。
