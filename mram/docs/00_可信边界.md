# SOT-MRAM 工程状态与可信边界

更新日期：2026-08-28

本文件是器件级细节；工程级三器件对照见 [docs/00_工程状态与可信边界.md](../../docs/00_工程状态与可信边界.md) 与 [docs/02_统一器件接口.md](../../docs/02_统一器件接口.md)。

## 1. 建模范围

| 项目 | 内容 |
|---|---|
| 单元 | 基本 **1T1MTJ** 读路径 + 选中写路径 Qcrit 筛选网表 |
| CMOS | PTM 32 nm LP + 与 ROM 同结构的读列外围 |
| MTJ | 线性 R/C 代理；**§7.1** R_P=10 kΩ、R_AP=20 kΩ、TMR=100%（参数汇总表） |
| 写操作 | I_write=100 μA、I_CSOT=80 μA、T_switch=1 ns（参数汇总 §7.1） |
| 读操作 | I_read=30 μA（文档锚点；网表为电阻分压）（参数汇总 §7.1） |
| CMOS 变异 | RSD 8%、σ_VOS=6 mV、σ_SM=10 mV（参数汇总 §3 / §7.1） |
| 辐射 | 重离子 + 质子（LET 代理）SET 于 GBL/SA；RPP 工程包络 |
| 环境 | 400 km、51.6°、5 年、1.0 g/cm² Al（共用 SPENVIS） |

## 2. 可以使用的结果

- `transient_read.heavy_ion_lower_bound_*`：ngspice Qcrit + RPP + LET 积分得到的 **读窗口瞬态下界**（§7.1 基线，2026-08-28 characterize）。
- `transient_read.proton_*`：同 Qcrit 样本的质子读窗口下界（硅 LET 代理）。
- `post_write` 写/hold Qcrit 筛选比值（screening_only）。
- `results/mram_spice_response.tsv`：P/AP 读裕量与 `NPRESENT` 扫描。

中心工程值（nominal HI）：**1.417e-24** / active bit / 0.72 ns。

## 3. 与 SRAM / ROM 的关系

| 对比 | 结论 |
|---|---|
| vs ROM | **读链对齐**（同结构外围、同 Qcrit→RPP→LET、同 claim_level） |
| vs SRAM | **不对齐主通道**：SRAM 交付驻留翻转；MRAM 交付读窗口瞬态 |
| 禁止 | 把三器件数字排成“谁更可靠”而不声明通道与归一化口径 |

## 4. 刻意缺失的通道

| 通道 | 状态 | 原因 |
|---|---|---|
| `persistent_state` | `missing` | 文献报告 MTJ 存储对 HI 不翻转；无目标宏 per-bit σ 可积分 |
| `post_write` | `screening_only` | SOT 写窗口 Qcrit（§7.1: 100 μA, 1 ns） |
| `correlated_macro_event` | `missing` | 译码/SEFI 未进网表 |
| `permanent_failure` | `missing` | MgO 击穿仅极端 LET 报告，未转永久失效统计 |

## 5. 文献依据（参数与机制）

- **SOT-MRAM辐照错误建模参数汇总.md** — 默认电气/变异/写时序基线（§7.1 / §7.2）
- arXiv:2404.09125 / IEEE EDL 2024 — 补充 fab 锚点（TMR、R_P、Ic、R_SOT，300 mm 平台）
- IEEE TMAG 2018.2830701 — SOT-MRAM 外围 SEU 硬化；MTJ 本征不敏感
- IEEE TNS 2025.3583702 — SOT 阵列 HI 辐照；Ic/TMR 稳定，极端 LET 下 MgO 短路

## 6. 不可声称的内容

- 不能把读窗口下界当成“SOT-MRAM 总 BER”。
- 不能把 MTJ 电阻读代理当成 foundry Verilog-A 开关模型。
- 不能在没有束流 σ 的情况下声称非易失存储态翻转率。
- 不能将 HI 与质子读概率直接相加而不做并集模型。
