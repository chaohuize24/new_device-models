# PTM 32 nm LP model provenance

- File: `32nm_LP.pm`
- Source: https://mec.umn.edu/ptm
- Model class: low-power 32 nm bulk CMOS, BSIM4 `level=54`
- Verified use: ngspice circuit workflow, Qcrit screening and relative PVT/architecture trends in this release.

This is a public predictive technology model, not a manufacturable 28 nm foundry PDK. It must not be described as production parameters for the target memory. Replace it with the selected process PDK and PEX before silicon-level delay, energy, yield or absolute Qcrit claims.
