# RXTE/HM628128 在轨数量级检查

这里验证的是：给定与任务相符的 SPENVIS 屏蔽后质子谱和独立地面 `σp(E)`，本地积分能否得到与公开在轨月均日错误率同数量级的结果。

运行：

```bash
python3 sram/validation/xte/run_xte_validation.py
```

预期比值：

- 1996-07：预测/公开日均率约 `1.631`；
- 2002-07：预测/公开日均率约 `2.088`。

250/day 和 70/day 是论文给出的月均日率锚点，不是“恰好观测一天得到 250/70 个事件”。因此本目录不从它们构造 Poisson 计数置信区间。该检查支持积分链条的数量级能力，不验证目标 28 nm SRAM，也不验证从 ngspice Qcrit 生成绝对截面的能力。
